# Промпты

Формат запроса (поля из `yue2.protocol.SongRequest`):

| поле | что класть |
|---|---|
| `style` | язык, жанр, инструменты, характер вокала, темп. Это единственное место для «как звучит» |
| `lyrics` | только слова, с тегами `[Verse]`, `[Chorus]`, `[Bridge]`. Никаких пометок для модели |
| `cot` | `full` (мелодия+аккорды, редактируемо), `melody` (только мелодия, аккомпанемент свободный), `off` (без плана) |
| `seed` | для повторяемости, не гарантирует бит-в-бит на другой карте |
| `abc` / `abc_path` | своя партитура в ABC, только с `full` или `melody` |
| `cfg_scale` | по умолчанию 1.0 (`off`: 1.01), трогать в последнюю очередь |

- `neon_garage.json` — английский синтвейв, безопасный первый тест.
- `moscow_rain.json` — русский. В доках языки не перечислены, примеры только английский и китайский. Это эксперимент: смотрим, поёт ли по-русски вообще.
